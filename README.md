# AI_voice_summarizer1
An AI program that transcripts audio into text using API's like Whisper and also GPT for summarizing the whole content.
Features:
- Upload audio
- Speech-to-text using OpenAI
- Summarization
- Flask backend
- HTML/CSS/JS frontend

Live Demo Video of the project
[AI Voice Translator Demo](assets/demo.gif)

Tech Stack

- Python
- Flask
- Whisper
- Ollama
- Qwen
- HTML
- CSS
- JavaScript
